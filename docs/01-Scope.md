# Proje Kapsamı

## MVP Kapsamı

Bu proje, müşterilerin üyelik oluşturmadan işletmelerden randevu almasını ve işletme sahibinin bu randevuları yönetmesini sağlayan mobil öncelikli bir uygulamadır.

### Müşteri Tarafı

- İşletmeleri listeleme
- İşletme detaylarını görüntüleme
- Tarih seçme
- Uygun saatleri görüntüleme
- Ad, telefon ve not bilgisi girme
- Randevu oluşturma

### İşletme Sahibi

- Giriş yapma
- Gelen randevuları görüntüleme
- Randevuyu onaylama
- Randevuyu iptal etme
- Randevuyu tamamlandı olarak işaretleme

### Backend

- REST API
- PostgreSQL veritabanı
- JWT kimlik doğrulama
- Slot yönetimi
- Randevu çakışma kontrolü

## MVP Dışında

Aşağıdaki özellikler ilk sürüme dahil değildir:

- Müşteri üyeliği
- Online ödeme
- SMS bildirimi
- Push bildirimleri
- Çoklu şube desteği
- Çoklu çalışan desteği
- Yorum ve puanlama
- Yönetici paneli

## Bonus Özellikler

- Google Calendar entegrasyonu
- React tabanlı web arayüzü
